# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro (static site generator), deployed to Cloudflare Pages. Source data is a static JSON file (`data/sermons.json`) generated by a one-time/re-run scraper script, not a live database.

## Users

Primary user: the pastor (currently preaching at Heritage Baptist Church, theheritagechurch.org), archiving his own sermon library for permanent, independent ownership ahead of retirement — so the record outlives his access to the church's systems. The site is intended to go public eventually as his own ministry's sermon archive (visitors seeking a specific sermon/teaching), not just a private personal backup — but ownership and durability, not audience growth or SEO, remain the driving requirement.

## Product Purpose

"Mature Ministries" is a 1:1 personal archive of the pastor's existing sermon library: every sermon's title, date, scripture reference, series/category, full text, embedded YouTube video, and downloadable sermon-guide PDFs (multiple languages), pulled from theheritagechurch.org/library/ and re-hosted under the pastor's own domain/repo. Success = every sermon in the source library is present, browsable, searchable, and independently owned — nothing lost when he no longer has access to the church's site.

## Positioning

Not a competing public ministry brand — a faithful, durable personal mirror of one specific pastor's own body of work, owned outside of any one church's infrastructure.

## Operating Context

- Source: theheritagechurch.org, WordPress site using a custom `sermon` post type exposed at `/wp-json/wp/v2/sermon` (metadata only — no post body in the API) plus each sermon's own page (full transcript text, YouTube link, PDF sermon-guide download links).
- 498 sermons at time of scrape (2026-09-10).
- Scraper: `scripts/scrape_sermons.py`, checkpointed/resumable, writes `data/sermons.json` and downloads guide PDFs + thumbnails into `public/assets/`.
- Hosting: Cloudflare Pages, deployed from a new GitHub repo under the `zackcollier87` account.

## Capabilities and Constraints

- Videos are embedded via YouTube's player (video IDs extracted per sermon), never re-downloaded/re-hosted as video files.
- Full sermon transcript text is scraped from the pastor's own published sermon pages (his own authored content).
- PDF sermon guides (available in multiple languages per sermon) are downloaded and re-hosted as static assets.
- Undecided: custom domain for the live site (none provided yet — will initially deploy on the default `*.pages.dev` subdomain).
- Undecided: whether new sermons published after this initial clone should sync automatically (out of scope for this build unless requested).

## Brand Commitments

Site name: "Mature Ministries" (confirmed). No logo, color palette, or other brand assets provided yet — visual identity is being originated for this build (see DESIGN.md once written), not inherited from the source church site.

## Evidence on Hand

- Live source data at theheritagechurch.org/library/ and its REST API — real, in-progress scrape, not sample/mock data.
- No testimonials, press, or case studies apply; none should be invented.

## Product Principles

1. Completeness over polish shortcuts — every sermon in the source library must make it into the archive; a good-looking site with gaps fails its purpose.
2. Read-first experience — visitors are here to find and consume a specific sermon (by date, series, or scripture), not to be marketed to.
3. Durability — the pastor must be able to fully own, export, and maintain this independent of any other church's systems.
4. Respect the source as the author's own original work — never present it as belonging to anyone else, never strip attribution to Pastor Wayne / Heritage Baptist Church's original publication.

## Accessibility & Inclusion

No explicit standard mandated; build to solid baseline accessibility (semantic HTML, captioned/embedded video, readable contrast, keyboard-navigable search/filter) since transcripts already serve users who can't watch video.
