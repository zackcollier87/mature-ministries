# Mature Ministries

A complete archive of Pastor Wayne Edwards' sermon library — video, full transcript, and multi-language study guide PDFs for all 498 sermons — cloned from [theheritagechurch.org/library/](https://theheritagechurch.org/library/) so the record is owned independently of any one church's website.

- **Live site:** https://mature-ministries.pages.dev
- **Repo:** https://github.com/zackcollier87/mature-ministries

Each sermon page includes standalone audio (extracted from the sermon's YouTube video, 48kbps mono MP3, hosted on a Cloudflare R2 bucket) with an in-page player and a download link, for 492 of the 493 sermons that have video.

See `PRODUCT.md` for product context and `DESIGN.md` for the visual system.

## Two ways to host this

1. **Static (Astro + Cloudflare Pages)** — what's currently live at https://mature-ministries.pages.dev. Best if nobody needs to edit content through a GUI; updates go through re-running the scraper and redeploying.
2. **WordPress** — see [`wordpress-theme/README.md`](wordpress-theme/README.md). Built for Brian, whose own hosting/plugin setup is WordPress-based and doesn't fit a static Cloudflare Pages site. Same design and same 498 sermons, delivered as a self-contained theme + WXR import file so it's editable day-to-day through normal WP Admin.

## Updating the sermon data

All sermon content lives in `data/sermons.json`, generated by `scripts/scrape_sermons.py` against the source church site's WordPress REST API + each sermon's own page (for transcript, video link, and PDF guide links, which aren't exposed via the API). To pick up sermons published after this initial clone:

```sh
python3 -m pip install --user requests beautifulsoup4   # if not already installed
python3 scripts/scrape_sermons.py                        # safe to re-run; skips already-scraped entries
npm run build
wrangler pages deploy dist --project-name=mature-ministries
```

13 older/special sermons had no video linked on their original source page; 8 of those were found and matched by hand-searching the church's YouTube channel (`@HeritageBaptistChurchPerry`) and are flagged `"_youtube_manually_matched": true` in the data. 5 remain unmatched (see `PRODUCT.md`'s "Known data gaps").
